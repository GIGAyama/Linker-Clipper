# リンカークリッパー（学習サイトリンク集）

先生が見つけた学習サイトを、**学校・自治体でひとつのリンク集にためていく**しくみです。

- **リンク集本体**（Google Apps Script）… ためたサイトを一覧で見せる。先生が開く画面
- **収集用の Chrome 拡張機能**… ブラウザで見ているページを「あとで登録」にためて、まとめて送る
- **Pages 側**（linker-clipper.giga-school.com）… 利用規約・プライバシーポリシーの掲示

## この構成のだいじな点

**リンク集は、導入した学校（または自治体）が自分で持ちます。**
スプレッドシートも Apps Script のデプロイも、その学校の先生のアカウントの下にあります。
作者（GIGA山）のアカウントは一切関与しません。データを預かることも、
シートの共有先になることもありません。

Apps Script を「**実行するユーザー: 自分**」でデプロイするので、
リンク集を見る他の先生は**スプレッドシートの権限を持つ必要がありません**。
デプロイした先生のアカウントが代理で読み書きします。名簿や児童の情報は
一切あつかわないため、リンク集そのものは学校の中で広く開いて構いません。

## 導入手順（学校・自治体ごとに1回）

### 1. スプレッドシートを作る

Google ドライブで新しいスプレッドシートを作ります。名前は何でも構いません
（例:「学習サイトリンク集」）。**このシートがリンク集の本体**になります。

### 2. Apps Script にコードを入れる

1. そのスプレッドシートで **拡張機能 → Apps Script** を開く
2. `Code.gs` の中身を、このリポジトリの `Code.gs` で置きかえる
3. 左の「ファイル」で **＋ → HTML** を選び、名前を `index` にして、
   このリポジトリの `index.html` の中身を貼る
4. 保存する

### 3. あいことば（共有シークレット）を決める

拡張機能から勝手に書き込まれないようにするための合言葉です。**必須です。**

1. Apps Script の **プロジェクトの設定 → スクリプト プロパティ**
2. `CLIPPER_SHARED_SECRET` という名前で、推測されにくい文字列を入れる
   （20文字以上を推奨。パスワード生成器の出力で構いません）

未設定のままデプロイすると、受け取り口は**閉じたまま**になります
（誰でも書き込める状態にはなりません）。

### 4. AI での自動分類を使う場合（任意）

登録したページの教科・学年をAIに推測させたいときだけ設定します。

- スクリプト プロパティに `GEMINI_API_KEY` を追加
- 設定しなくてもリンク集は動きます（分類は手で選ぶことになります）

### 5. デプロイする

1. Apps Script の右上 **デプロイ → 新しいデプロイ**
2. 種類は **ウェブアプリ**
3. **実行するユーザー: 自分**
4. **アクセスできるユーザー**:
   - 学校の Google Workspace 内だけで使う → 同じドメインのユーザー
   - 個人アカウントの先生も混ざる → 全員
5. デプロイして出てくる **`https://script.google.com/macros/s/…/exec`** の URL を控える

この URL がリンク集のアドレスです。先生方に配ってください。

> **更新のとき**は「新しいデプロイ」ではなく、**デプロイを管理 → 既存のデプロイを編集**
> して新しいバージョンを選びます。「新しいデプロイ」を作ると URL が変わり、
> 配布済みのリンクが全部切れます。

### 6. Chrome 拡張機能を入れて、つなぐ

1. 拡張機能を読み込む（`manifest.json` のあるフォルダを「パッケージ化されていない拡張機能を読み込む」）
2. 拡張機能のアイコンから設定を開き、次の2つを入れる
   - **GAS のアドレス**: 手順5で控えた `…/exec`
   - **あいことば**: 手順3で決めた文字列
3. 学習サイトを開いて「あとで登録」にためる → まとめて送る

---

## 更新の受け取り方

このリポジトリの `Code.gs` / `index.html` が更新されたら、手順2をやり直して
手順5の「既存のデプロイを編集」で反映してください。**リンク集のデータ
（スプレッドシートの中身）は消えません。**コードだけが入れかわります。

拡張機能を更新したときは、拡張機能側を読み込み直します。
設定した URL とあいことばは残ります。

---

## 注意点

- **あいことばは、先生どうしでも安易に共有しないでください。**
  これを知っていれば、誰でもリンク集にサイトを登録できます。
- リンク集の URL を知っている人は一覧を見られます（手順5のアクセス設定の範囲内）。
  児童の情報はあつかわないため通常は問題になりませんが、**メモ欄に
  児童名や校内の内部情報を書かない**ようにしてください。
- `index.html` は **Apps Script のテンプレート**です（`google.script.run` を使います）。
  GitHub Pages 側（linker-clipper.giga-school.com）が配信しているのは
  規約とプライバシーポリシーで、リンク集本体は各学校のデプロイにあります。
